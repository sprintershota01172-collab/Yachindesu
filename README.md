# 家賃です。

楽天カード請求額を入力するだけで、ふたりの毎月の振込額をリアルタイム計算する、スマートフォン向け静的Webアプリです。

## 計算式

- 固定費: 翔太 61,000円 + 志穂 41,000円 = 102,000円（設定変更可）
- 変動費: 楽天カード請求額 − 固定費の合計
- 変動費は半額ずつ負担
- カードとは別の食費チャージ: 28,000円（設定変更可、折半）
- 各人の振込額 = 各人の固定費 + 変動費負担 + 食費負担
- 割り切れない1円は翔太側が負担する

**例**: カード132,000円なら、翔太90,000円、志穂70,000円。合計160,000円。

## 機能

- 計算ボタン不要。請求額の入力と同時に再計算
- 支払額と内訳を見やすく表示
- 設定・請求額をブラウザのローカルストレージに保持
- 振込額を1タップでコピー
- PWAとしてホーム画面に追加でき、キャッシュ後はオフラインでも利用可能
- アカウント登録・外部API・外部ライブラリなし
