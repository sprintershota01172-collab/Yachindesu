# 家賃デス — ふたりの家計管理

チャコール × 生成り × グレージュに、手書き風の日本語フォントを組み合わせたiPhone向けの家計精算アプリ。4つのタブはスクロール不要で操作できます。

**アプリ**：https://sprintershota01172-collab.github.io/Yachindesu/

## アカウント登録・別端末での再ログイン

TABIと同じバックエンドの暗号化ルームAPIを利用していますが、**アカウントは家賃デス専用**で、TABIのアカウントとは別です。Firebaseの設定は不要です。

1. 最初に「新規登録」を押し、**半角英数字から始まる4〜32文字のID**と**1文字以上のパスワード（文字種・長さの上限なし）**を決めます。
2. 「アカウントを作成」で、この端末の家計データを共有ルームに保存し、その共有ルームへの参照をアカウントに紐付けます。
3. 次回からは同じ端末でログイン状態が保持されます。パスワードの長さや文字種は自由ですが、短いパスワードは推測されやすいため長い文字列を推奨します。
4. 別のiPhoneでアプリを開いた場合は、同じIDとパスワードで「ログイン」すると、共有ルームから家計データを復元できます。
5. 右上のアカウントボタンで「マイアカウント」を開き、「ログアウト」すると、再度IDとパスワードが必要になります。

**夫婦が別々のアカウントを作成する場合**：夫側が登録し「共有」タブで招待リンクをコピー。妻側でそのリンクを開き「新規登録」を実行すると、妻側のアカウントも同じ家計ルームに紐付きます。すでにアカウントがある妻側でも、招待リンクを開いてログインすれば共有先が切り替わります。

**アカウントの認証仕様**
- IDから決まるサーバー側のルームIDと、パスワードからPBKDF2-SHA256（650,000回）で導出した256bit鍵を使い、アカウント内の共有ルーム参照をAES-GCMで暗号化して保存します。
- 生のパスワードは保存・送信しません。ただし**ログイン状態を維持するための導出鍵および共有鍵は端末のlocalStorageに保存されます**。端末自体の画面ロックを利用してください。
- ID・パスワードの再設定、メール認証、本人確認、パスワードリセット機能はありません。**忘れた場合、他端末からの復元はできません。**
- 同じID・パスワードを何度でも使用でき、クラウドに家計データがある限り再ログイン可能です。
- 登録・別端末からのログイン・同期には通信環境が必要。既存端末でログイン情報とデータが残っていれば、オフライン起動できます。
- ログアウト時もブラウザ内の月別履歴は端末に残りますが、認証画面によって隠されます。端末を譲る前にはブラウザのデータ削除なども行ってください。
- **TABIと同じ外部同期サービスに依存**します。接続の可否・稼働状況は実機で確認が必要です。

## 計算と月別履歴

- 最初の楽天カード請求額は**0円（空欄で「0」と表示）**。未登録月は0円から開始します。
- 固定費：翔太61,000円／志穂41,000円、合計102,000円。食費：合計28,000円。
- 請求額が未入力・0円または固定費の合計未満の場合、振込額は「—」で未確定表示し、コピーや登録を無効化します。
- 有効な請求額では、各自固定費＋（請求額−固定費合計）÷2＋食費÷2を計算します。
- 月別履歴を登録すると、グラフ・前月との差額を確認できます。
- 夫婦での更新はオンライン時に約3秒間隔で同期。オフライン中も端末に保存し、接続復帰後に同期します。同じ月を同時編集した場合、より新しい更新時刻が優先されます。
- 月別記録の保存は「この月を登録」ボタンで確定します。

## 省スペース・オフライン起動

HTML、スタイルシート、JavaScript、アイコンをService Workerで事前キャッシュします。手書き風のオンライン書体「Klee One」は通信時に読み込み、利用できない場合は端末の明朝系書体を代替します。初回アクセス後、計算・履歴・設定はネットなしで動きます。iPhone Safariの「共有」→「ホーム画面に追加」でアプリ形式で使えます。Safariとホーム画面アプリは端末によって保存領域が分離することがあるため、ホーム画面追加後はアプリ内でログインしてください。

## 通知の動作範囲

「通知」タブで1〜31日の希望日を選びます。指定日が存在しない月は月末扱い。指定日にアプリを開くか前面に戻したときは「ヤチントウロクビデス！」と表示します。

**未実装**：アプリを完全に閉じていても指定日に確実に届く定期プッシュ通知。これにはサーバー側の定期実行・Push購読情報と送信処理が必要です。TABIで使われている共同編集の通知とは別です。

## 主な実装ファイル

- \`index.html\`：ログイン画面・4タブ
- \`app.css\`：基本UI
- \`design.css\`：新しいデザインと認証画面
- \`app.js\`：計算・月別履歴・設定・同期連携
- \`yachin-sync.js\`：暗号化ルームと競合処理
- \`yachin-account.js\`：アカウントの登録・認証・復元
- \`auth-ui.js\`：ログイン／新規登録／ログアウト画面
- \`sw.js\`：オフラインキャッシュ

※ 以前のFirebase設定ファイルは現在使用されていません。
