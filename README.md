# 家賃デス

スマートフォン向けのコンパクトな夫婦家計アプリ。GitHub Pagesで公開するPWAです。

**アプリURL**：https://sprintershota01172-collab.github.io/Yachindesu/

## できること

- **計算**：楽天カード請求額を入力して、それぞれの振込額を即時計算。対象月を選んで「この月を登録」を押す
- **月別**：過去24か月の記録、直近6か月のグラフ、前月との差額を表示
- **共有**：TABIと同じ暗号化同期サーバーを利用して、招待リンクで夫婦のデータを共同編集
- **通知**：毎月1〜31日の希望日を設定し、アプリを開いたときに「ヤチントウロクビデス！」と知らせる
- **オフライン**：PWAが一度読み込まれれば、アプリの起動、計算、月別記録、通知日の設定は通信なしで利用可能

初期設定：翔太の固定費 61,000円、志穂の固定費 41,000円、食費チャージの合計 28,000円。変動費を折半し、端数1円は翔太側負担。

## 夫婦で共同編集する（Firebase設定は不要）

このバージョンでは、旅行プランナーTABiと同じ **暗号化共有ルーム API** を利用します。

1. 翔太の端末でアプリを開き、「共有」タブの **「共有ルームを作成」** をタップします（初回はインターネット接続が必要）。
2. 表示された **「招待リンクをコピー」** を押して、LINEなどで志穂に送ります。
3. 志穂のiPhoneでリンクを開くと、同じ家計のルームに参加し、登録済みの月別データが同期されます。
4. その後は両者の「計算」タブで対象月と請求額を設定し、「この月を登録」を押すと、共有相手にも更新が反映されます。
5. オンラインではおよそ3秒ごとに確認し、通信が切れている間は端末に保存。オンライン復帰後に差分をマージします。

共有データは **Web Crypto API の AES-GCM 256bit** で暗号化して保存され、サーバーへ平文の家計データや暗号化鍵を送信しません。招待リンクに編集用の鍵が含まれますので、**他人にリンクを共有しないでください**。TABIの旅行ルームとは独立した別のUUIDルームに保存します。

共有端末で同じ月を同時編集した場合は、更新時刻を比較して新しい記録を優先します。異なる月の編集は統合します。共有相手がまだ反映されていない場合はオンラインに戻して再度アプリを開いてください。

**同期接続についての注意**：同期先はTABiでも使用される外部サービス \`tabi-planner-sync.prettybell7.chatgpt.site\` です。GitHub Pagesへのファイル公開は完了しても、外部サービスへの接続が成功するかは端末での動作確認が必要です。サービス停止・仕様変更時は同期できません。端末内のデータは残ります。

## オフラインとデータ保持

- HTML・CSS・JavaScript・アイコンをService Workerでキャッシュし、起動時はキャッシュを優先します。
- 月別の記録と設定は、端末の \`localStorage\` に保存されます。
- オフラインで編集したデータは、共有ルーム接続済みなら通信復帰後に同期を試みます。
- iPhoneではSafariで「共有 → ホーム画面に追加」を選んでください。
- **ブラウザのサイトデータ削除／PWA削除でローカルデータが消える可能性があります。**

## 毎月の通知

「通知」タブで日付とON/OFFを設定します。31日など、月によって存在しない日付は月末扱いです。

**現時点の実装**：指定日にアプリを開いたとき、または前面に戻したときに通知を試みます。

**未実装**：アプリを閉じたまま指定日に確実に届くプッシュ通知。実現するには、バックエンド側にプッシュ購読登録・定期実行・通知送信機能が必要です。TABIの編集通知とは異なる「毎月の日時指定」のため、現時点では保証できません。

## 主要ファイル

- \`index.html\`：4つのタブ
- \`app.css\`：モバイル向けデザイン
- \`app.js\`：月別計算、ローカル保存、グラフ、通知UI
- \`yachin-sync.js\`：TABI互換の暗号化共同編集・競合処理
- \`sw.js\`：キャッシュ優先の高速起動・オフライン
- \`manifest.webmanifest\`：インストール情報

\`firebase-config.js\` と \`firestore.rules\` は以前の方式のファイルで、現在のアプリからは読み込んでいません。
