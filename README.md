# 家賃デス

夫婦の楽天カード請求額を入力するだけで、固定費の個別負担と変動費の折半、食費チャージを計算するスマホ向けPWA。

**アプリURL**：https://sprintershota01172-collab.github.io/Yachindesu/

## 使い方

1. **計算**：請求額を入力すると即時計算。対象月を選んで「この月を登録」。
2. **月別**：過去の登録額、直近6か月の推移グラフ、前月との差額を確認。行をタップして再編集。
3. **共有**：Firebase連携後、家族ルームと招待リンクで2台を共同編集。
4. **通知**：毎月1〜31日の好きな日を設定。「ヤチントウロクビデス！」とお知らせ。

初期値：固定費 翔太61,000円 / 志穂41,000円、食費28,000円。変動費は半分ずつ（端数1円は翔太側）。
入力・月別データは端末に保存されます。月別データは登録ボタンを押して確定します。

## オフラインと速度

HTML・CSS・JavaScript・アイコンをService Workerで先読みキャッシュします。初回読み込み後は、通信がなくても計算・月別履歴・通知日設定が動きます。データはブラウザのlocalStorageに保存されます。アプリ削除・ブラウザのデータ削除で消えることがあるため注意してください。

iPhoneのSafariで「共有」→「ホーム画面に追加」を選ぶとホーム画面から起動できます。

## 夫婦で共同編集するための初期設定（未設定だと端末保存のみ）

GitHub Pagesは静的配信なので、端末間でデータを同期するにはデータベースが必要です。本アプリは**Firebase Authentication（匿名認証）** と **Cloud Firestore** に対応したクライアントコードを用意しています。

1. [Firebase Console](https://console.firebase.google.com/) でFirebaseプロジェクトを作成します。
2. 「プロジェクトの設定」→「マイアプリ」から**ウェブアプリ**を追加し、画面の \`firebaseConfig\` を確認します。
3. 「Authentication」→「Sign-in method」で **匿名（Anonymous）** を有効化します。
4. 「Firestore Database」でデータベースを作成し、「Rules」タブへリポジトリ内 \`firestore.rules\` の内容を貼って公開します。**ルールなしでテストモードを使い続けないこと。**
5. リポジトリの \`firebase-config.js\` の \`window.YACHIN_FIREBASE_CONFIG\` に、Firebaseウェブアプリの \`apiKey\`、\`authDomain\`、\`projectId\`、\`appId\` を設定してGitHub Pagesへ反映します。**秘密鍵やサービスアカウント鍵は設定しないでください**。
6. 夫側で「共有」→「共有ルームを作成」、奥さんに招待リンクを送信。奥さんが開くと同じルームへ参加します。

ルームIDは暗号学的乱数24バイトから生成し、招待リンクのフラグメントに保持します。**リンク自体が編集権限**のため第三者への転送は避けてください。これは個人用の簡易共有方式です。参加者別の権限管理や招待の失効には、別途サーバー側の招待・メンバー管理が必要です。

Firestoreのオフラインキャッシュと端末のローカル保存を併用します。別端末からの更新が反映されるにはネットワーク接続が必要です。同じ月を同時編集した場合は最後に同期された更新が優先されることがあります。

## 通知の動作範囲（重要）

「通知」タブで1〜31日を選べます。対象の月に指定日が存在しない場合は月末にお知らせします。

- **現在利用可能**：アプリを開いたとき／再び前面に戻ったときに、指定日ならメッセージを表示します。通知が許可されており対応環境なら、その時点でOS通知の表示も試みます。
- **未対応**：アプリを完全に閉じている状態で毎月決まった時刻にプッシュ通知を送信する仕組み。これは静的GitHub Pagesやブラウザのタイマーだけでは実現できません。
- **完全対応に必要**：Firebase Cloud Messaging（iOSではホーム画面に追加したPWA・通知許可が必要）＋プッシュ購読情報の保管＋Cloud Functionsなどの定期実行サーバー。Firebase連携後に設置します。運用にはプランや費用の確認が必要です。

## 実装ファイル

- \`index.html\` UI / 4タブ
- \`app.css\` iPhone向けコンパクトデザイン
- \`app.js\` 計算・月別グラフ・保存・通知・Firebase同期
- \`firebase-config.js\` Firebase Web設定（初期値は未接続）
- \`firestore.rules\` Firestore権限制御
- \`sw.js\` オフラインキャッシュ、通知タップ時の起動処理
